SEIDR — Interactive Portal

How to use
----------
1) Keep all files in the same folder:
   - index.html (this file is the entry point)
   - CAPEX.html
   - comparison.html
   - ESIA3.html
   - LLI5.html
   - OEMcomparison.html
   - offtake.html
   - projectbuilder.html
   - schedule.html
   - Screening_Result.html

2) Open index.html in your browser. Use the left menu (or Ctrl/Cmd+K quick find) to jump between pages.
   The pages are embedded and remain fully interactive.

3) Share with colleagues:
   - Zip the folder and send it directly; they can open index.html locally.
   - Or drag the folder into a static host (GitHub Pages, Netlify Drop, Vercel drag-n-drop, or S3/CloudFront).

Notes
-----
- Each tool keeps its own interactivity; the portal acts as a shell for navigation.
- The "Open in new tab" button lets you pop out the current tool if you prefer a full page.
- The portal remembers the last page you visited.
